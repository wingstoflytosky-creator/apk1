# Uploaded asset assessment (2026-11-16)

The ZIP includes the 3 source models referenced by the game.

| User upload | Included in v1.1? | Why |
|---|---|---|
| `Near_future_soldier__0123183957.glb` (7 MB) | YES -> `assets/soldier.glb` | Native Godot-compatible GLB; contains mesh, material and texture. No animations embedded. |
| `AK-74_pack.fbx` (~8 MB) | YES | Native Godot 4.3 FBX import. It references various external albedo/normal/metalness PNGs which were not uploaded, so appearance may be untextured. |
| `drone.fbx` (~1.7 MB) | YES | Native Godot 4.3 FBX import; used as aerial enemy. |
| `t-90a(Elements_of_war).FBX` (~31 MB) | NO | Legacy FBX (version 6100), large mobile asset. Needs conversion/optimization and visual checking before inclusion. |
| `Lancelot.fbx` (~168 MB) | NO | Too large for convenient GitHub browser upload (individual file >100 MB Git hard limit) and too heavy for this mobile prototype without optimization. |
| `ammo_box.max`, `ammo_box(1).max` (~2.4 MB each) | NO | 3ds Max native files; must export to glTF/GLB or FBX using compatible modeling software. Simple pickups are generated by code instead. |
| `Ammo&Prop+Unity.rar` (~214 MB) | NO | Large Unity asset archive; needs unpacking, conversion and rights review. Not needed for prototype. |

Before serious production use, optimize triangle counts, textures (e.g. KTX2/ASTC as appropriate), transforms, LOD, animations and material usage for mobile hardware. Model names do not establish redistribution rights.
